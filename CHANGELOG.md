# Changelog

- 4.0-class Agent Skill Network / collective-intelligence architecture delivered under the 3.x line.
- Personal and federated deployment modes share one core.
- Knowledge Graph expanded into a visibility-aware Knowledge Mesh.
- Agent teams, capability-aware planning, Skill Router, Skill lineage and runtime recommendation added.
- Explainable governance decision ledger and resource governance added.
- Privacy budgets, selective disclosure and aggregated telemetry controls added.
- Global benchmark federation added.
- Host/Agent/User Neo dashboards added.
- Python, Node.js and Go Agent integration surfaces aligned.
- Optional Prediction Market added behind an explicit feature flag; disabled by default.
- Security hardening and release gate tooling expanded.
- Extensive installation, Agent protocol, architecture and contributor documentation refreshed.
